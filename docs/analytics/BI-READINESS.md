# BI / Analytics Readiness

InteliMine is analytics-platform neutral. The application should expose governed datasets that can be loaded into the mine's preferred reporting, BI, data-platform or warehouse tooling.

Recommended downstream model:

Operational database → governed analytical facts/dimensions → warehouse or lakehouse if required → preferred BI / analytics platform

The four primary fact families are reporting compliance, structured checks, immutable observations and managed issues.
