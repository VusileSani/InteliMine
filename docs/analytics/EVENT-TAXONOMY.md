# MineMind Event Taxonomy — v1.3

Event types are controlled identifiers applied to immutable observations and managed issues. Employees select an event type rather than inventing the primary category in free text; narrative remains available for operational nuance and judgement.

v1.3 retains the compact core taxonomy while making generic safety/operations event types available to the broader seeded value-chain reporting roles introduced in MineMind v2.7. Mine-specific additions should be governed master data rather than new screen-specific enums.

Taxonomy changes must be versioned. Historical observations retain the `eventTaxonomyVersion` under which they were captured. Deactivating or renaming a current taxonomy item must not rewrite historical facts.
